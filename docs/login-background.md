# Fundo original do acesso PCIF

Os arquivos `public/login/sector-background.webp` e `sector-background-small.webp` foram copiados sem alterações de `wellingtonsantos1114-pixel/painel-web-pcif.`, commit `85a7bfbcf2ec93d1bb3bf92b3a2f100852106e15`, mesmos caminhos. O repositório de origem não foi modificado.

O login usa a versão menor em telas com até 600 px de altura, como no painel. `object-fit: cover` preserva proporções com recorte central superior. O painel escuro mantém textos e controles legíveis. Todos os estilos novos são limitados a `.shell--login`; ao entrar, imagem e classe são removidas. Login segue demonstrativo sem autenticação ou credenciais. Nenhum ícone foi criado ou substituído.
